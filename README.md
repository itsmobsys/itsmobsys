## 📦 Featured Project

### 🎮 Game Sorting for ClipWave

**YouTube video → game detection → cached result**

A lightweight Python game-detection module built without:

* ❌ Browser automation
* ❌ LLM calls
* ❌ Heavy dependencies
* ❌ Guessing from arbitrary titles

Instead it uses a **two-level cache**:

```text
YouTube
   ↓
Game extraction
   ↓
L1 Memory Cache
   ↓
L2 SQLite Cache
```

It also includes:

* Request coalescing
* Bounded concurrency
* Persistent caching
* TTL-based expiration
* Resource benchmarks
* Automated tests
* Graceful failure handling

[View the project →](https://github.com/itsmobsys/Game-sorting-for-clipwave)
